# Структура фронтенду

- app — запуск, контекст застосунку та загальні стилі.
- pages/planner — композиція головної сторінки й координація функцій.
- features — subjects, tasks, calendar, planning, prediction, account,
  google-calendar, gamification та notifications. Усередині — api, model, components.
- shared — HTTP-клієнт, спільні UI-елементи, хуки й утиліти.

usePlanner координує навігацію, мутації та дані сторінки. usePlannerEditors
відповідає за відкриття й початкові значення редакторів. useTimeLog у features/tasks
керує журналом фактичних сесій, ручним внесенням і видаленням; захищає стан
діалогу від відповідей застарілих запитів. useTasks зберігає колекцію завдань
та застосовує відповіді API. Обчислення розташування календарних блоків
залишаються в calendar/model, їх відображення — в calendar/components.

Об’єднання таблиць не ламає наявні маршрути обліку часу. API повертає завдання
з актуальними підсумками та окреме календарне представлення сесій. У тижневому
календарі розрізняються план, активний таймер і завершена робота.
